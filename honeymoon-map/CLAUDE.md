# 동유럽 허니문 로드맵

신혼여행(2026.12.21 ~ 2027.1.1) 일정·준비물·구글맵 길찾기를 한 페이지에 모은 정적 사이트.
Claude 앱에서 만든 것을 로컬(VS Code + Claude Code)로 옮겨 이어서 작업한다. 답변은 한국어로.

## 파일 구조
- `index.html` — 페이지 전체 (HTML/CSS/JS 한 파일, 외부 의존성은 Google Fonts뿐)
  - 아래 고정 탭 4개 (APG Tabs 패턴, 자동 활성화):
    - **오늘**: 도시 진행 표시 + 날짜 스트립 + 상단 고정 날짜 바 + 날짜 카드 하나(좌우 스와이프로 이동). 일정 탭 카드를 JS로 복제해 펼친 형태로 보여줌. 출발 전엔 D-day·진행률 타일 + 첫날 미리보기
    - **일정**: 노선도(접힘) + 꼭 지킬 일정 모아보기(접힘) + 도시별 접히는 날짜 카드 (생성 구간). 여행 중엔 오늘 카드가 펼쳐져 있음
  - 페이지 제목: "또치와 똥글이의 신혼여행". 화면에 여행사 이름(투어민)은 쓰지 않음.
  - 디자인 방향(frontend-design 플러그인으로 정함): 겨울 중부유럽 철도 여행. 주인공은 오늘 탭의 '다음 일정' 출발 안내판(--board 남색 + --board-gold 숫자)과 절취선 있는 기차표 카드. 나머지는 얇은 테두리·그림자 없음으로 조용하게.
    글꼴: 제목 Hahmlet, 본문 IBM Plex Sans KR, 시간·날짜(.mono 클래스) Barlow Condensed. 대문자 라벨·장식용 소제목은 쓰지 않음.
  - 모바일 우선 (최대 폭 600px). 원본 일정 문서는 저장소 루트 `itinerary.md` (비용 정보는 사이트에 넣지 않음)
    - **정보**: 긴급 연락처, 호텔 4곳, 나라별 카드, 꼭 알고 갈 것
    - **준비**: 시기별 할 일, 준비물, 아직 답 받을 것, 구글 내 지도 만드는 법
  - 테스트용 날짜 지정: `index.html?today=2026-12-26`
- `tools/build_maps.mjs` — 장소 목록(`P`)과 날짜별 일정(`CZ`, `AT`, `HU`)의 단일 소스.
  실행하면 `index.html`의 `<!-- DAYS -->` ~ `<!-- /DAYS -->` 구간을 다시 생성하고
  `data/honeymoon_places.csv`(구글 내 지도 가져오기용)를 다시 쓴다.
  (이 PC엔 Python이 없어 Node로 옮김. 예전 `build_maps.py`와 링크 결과 동일)
- 오프라인 지원(PWA): `manifest.webmanifest`, `sw.js`(서비스 워커), `icons/`(192·512·애플 180 PNG).
  - 페이지는 네트워크 먼저(끊기거나 4초 넘으면 저장본), 아이콘·CSV·글꼴은 저장본 먼저. **아이콘·CSV를 바꾸면 `sw.js`의 `CACHE` 숫자를 올린다.**
  - 서비스 워커는 http(s)에서만 동작 (file:// 로 열면 등록 안 됨). 연결이 끊기면 헤더 아래 안내 문구가 뜸.
- 택시 화면: index.html 스크립트의 `TAXI` 객체(호텔 이름·현지어 주소·언어)가 단일 소스. `data-taxi="키"` 버튼이 열고, 날짜 카드 '오늘 밤' 줄에도 생성기가 버튼을 붙임. 네이티브 `<dialog>`(APG 모달 패턴). **Leonardo 주소는 바우처 받으면 TAXI와 호텔 카드에 채울 것.**
- 현지어 한마디(정보 탭): index.html 스크립트의 `PHRASES` 배열(그룹 g, 한국어 ko, 한글 발음 pr{cs,de,hu}, cs·de·hu·en)이 단일 소스. 발음은 대략 표기. 기본 언어는 오늘 날짜 카드의 나라(cz→cs, at→de, hu→hu), 언어 버튼은 `aria-pressed`. 누르면 `#phrase` 대화상자(택시 화면과 같은 모양·동작).
- `data/honeymoon_places.csv` — 열: 이름, 주소, 날짜, 종류, 메모, 구글맵

## 작업 규칙
- 일정·장소 변경은 `index.html`을 직접 고치지 말고 `tools/build_maps.mjs`를 고친 뒤 `node tools/build_maps.mjs` 실행.
  - 날짜 카드 옵션: `where`(그날 도시, 오늘 탭 도시 진행 표시에 쓰임), `meal`(식사 칩, '포함'이면 초록·'예약'이면 와인색), `fixed`(꼭 지킬 것), `body`(항상 보임: 주의 note, 시간표, 길찾기), `notes`(더보기에 접힘: 팁), `places`(화면엔 안 나오고 CSV·내 지도용), `recs`(추천 더보기, P에 메모 '추천 · '로 시작), `stay`(오늘 밤 숙소)
  - 꼭 지킬 것: `fx(시간, kind, 이름, {status, place | dir:[출발,도착,mode], note, id, tag})` — `tag`는 일정 탭 접힌 목록에 시간과 함께 나오는 짧은 이름 (예: "09:20 셔틀")
    - kind: stay 숙소 · move 교통 · tour 투어 · book 예약 · ticket 입장
    - status: ok 확정 · tbd 미정 · book 예약 필요(`id` 필수, '예약함' 체크가 localStorage에 저장되고 같은 id끼리 동기화)
    - 오늘 탭 안내판: ① 오늘 남은 `HH:MM` 일정이 있으면 카운트다운 ② 없으면 오늘의 꼭 지킬 것(시간 미정 포함, 최대 3개) ③ 오늘 것이 없으면 다음 시간 일정.
    - 시간이 `HH:MM`으로 시작하면 카운트다운 대상. 바우처 받으면 '미정'을 실제 시간으로 바꾸고 status를 ok로
  - '여기서' 버튼(내 위치 출발 길찾기, 구글맵 URL에서 origin 생략): 동선은 `route(..., {here, hereMode})`, 꼭 지킬 것은 `fx(..., {here, hereMode})`.
    기본 목적지는 동선=도착지(열차는 출발역), 꼭 지킬 것=`dir`의 도착지 또는 `place`. 열차·셔틀처럼 **타러 가는 곳**이 다르면 `here`로 지정, 필요 없으면 `here: null`.
  - 일몰: 생성기의 `sunTime()`(NOAA 근사식, UTC+1)으로 계산해 날짜 카드 맨 위와 접힌 목록 요약에 표시. 도시는 `SUN_AT`(날짜→그날 해 질 무렵 있을 도시). 박명 끝(태양고도 −6°)도 함께 표시.
  - 시간표 `sched` 행의 세 번째 값 `'opt'` = 선택(흐리게 + '선택' 태그)
  - 일정 탭 맨 위 '꼭 지킬 일정' 모아보기는 `fixed`에서 자동 생성
- 테스트용 시각 지정: `index.html?today=2026-12-25&now=2026-12-25T14:00`
- 그 밖의 섹션(긴급 연락처, 호텔, 나라별, 꼭 알고 갈 것, 시기별 할 일, 준비물, 확인 목록, 노선도 SVG)은 `index.html`에서 직접 수정.
- 바우처를 받으면 정보 탭 '긴급 연락처'의 "바우처 후" 항목(투어민 비상연락처, 항공편·예약번호)을 채운다.
- 색은 `:root` 토큰만 사용. 라이트/다크 모두 확인. 모바일(400px)에서 가로 스크롤 금지.
- 체크박스 상태는 localStorage 키 `honeymoon-check`에 저장.
- 구글맵 링크 형식: 검색 `maps/search/?api=1&query=`, 길찾기 `maps/dir/?api=1&origin=&destination=&travelmode=&waypoints=a|b`.
  열차 구간은 `transit`으로 연다.
